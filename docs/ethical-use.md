# Aegis AI Ethical Use Policy

## Purpose

Aegis AI is a security research tool designed to help developers and security professionals identify and remediate vulnerabilities in LLM-powered applications.

## Authorised Use Only

**You may only use Aegis AI against systems you own or have explicit, written permission to test.**

Examples of authorised use:
- Your own LLM application in a development or staging environment
- Client systems during an authorised penetration test engagement
- Internal systems with approval from your organisation's security team
- Open-source LLM deployments you operate yourself

## Prohibited Uses

The following uses are strictly prohibited:

- Testing production systems without explicit written authorisation
- Testing third-party APIs or services without their consent
- Using attack templates to cause actual harm, data loss, or service disruption
- Submitting attack prompts to public AI services in violation of their terms of service
- Using Aegis AI to develop offensive tools for unauthorised access

## Legal Notice

Unauthorised computer access is illegal in most jurisdictions, including under:
- The Computer Fraud and Abuse Act (CFAA) in the United States
- The Computer Misuse Act in the United Kingdom
- Similar legislation in the European Union, Australia, and other regions

The authors of Aegis AI accept no liability for misuse of this tool.

## Responsible Disclosure

If you discover a vulnerability in a third-party system during authorised testing:

1. Do not exploit the vulnerability beyond what is necessary to confirm it exists
2. Document your findings carefully
3. Report the vulnerability to the system owner through their responsible disclosure programme
4. Allow reasonable time for remediation before any public disclosure

## Data Handling

- Never store real user data in attack templates
- Delete session data from the database once testing is complete
- API keys in reports are automatically redacted — verify this before sharing reports

## Acknowledgement

By using Aegis AI, you acknowledge that:
1. You have authorisation to test the target systems
2. You will use the tool responsibly and legally
3. You understand the potential impact of security testing on production systems
4. You accept responsibility for your actions when using this tool
